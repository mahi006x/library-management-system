# Library Management System

A full-stack Library Management System built using Spring Boot, React, MySQL, and JWT authentication.

## Tech Stack

- Java Spring Boot
- React + Vite
- MySQL
- Spring Security + JWT
- Axios
- Swagger/OpenAPI

## Features

- User registration and login
- Role-based access: Member and Admin
- Book catalogue
- Book request workflow
- Admin approval
- Return book workflow
- Fine calculation and payment
- Admin dashboard
- Swagger API documentation
